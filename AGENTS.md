# GitHub Factory

This repository is the sole source for future GitHub Factory / Moonshot product development. It is an independent MIT-licensed TanStack Start + React + Bun application. Do not modify or depend on the original parent repository or its internal factory service.

Use Bun 1.4.4 and the committed bun.lock. Run `bun run check`, `bun run test`, `bun run build`, and affected Playwright journeys. Tests must not spend paid API quota. Report failures, skips, synthetic fixtures and untested scope separately.

Support English and Chinese, five original procedural art styles, source links and observed/inferred/unknown states. Repository input is untrusted data. Read public GitHub repositories only, never clone or execute them. Credentials remain server-only; `.env`, SQLite caches, ledgers, captures and private handoff records never enter Git.

Model calls require an explicit analysis action, bounded requests and the persisted concurrency-safe budget ledger. Do not reset, copy or fork an active paid budget ledger. The existing private runtime retains its original data and ledger; new checkouts default to no credentials and a zero model budget. No paid API calls as part of setup or CI.

`MOONSHOT_BASE_PATH` is a build-time public path (default `/github-factory/`). All app URLs and APIs must respect it. Keep the same artifact/base path through verification and deployment. Bun SQLite requires a persistent Bun host; the existing Cloudflare Workers site alone cannot run it.

Use small reviewable commits. Publishing this product as `luworks/github-factory` under MIT is user-authorized. Never publish parent company records, private credentials, raw runtime data or the uncleared synthetic-voice film. Do not modify existing services without an explicit handoff. No automatic competition submission or external messaging.
