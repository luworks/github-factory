# Contributing

Use this repository for all GitHub Factory / Moonshot changes. Do not send changes to the original incubation repository.

Install with Bun 1.4.4 and `--frozen-lockfile --ignore-scripts`. Keep all five perspectives on the same typed world contract. Run type checks, unit tests, a production build and affected Playwright journeys. Browser fixtures are synthetic; real upstream/provider checks must be reported separately. Tests and CI must not consume paid quota.

Do not commit `.env`, SQLite files, ledgers, cached surveys, captured repository data or generated media. Report security issues privately through the maintainer's GitHub contact rather than publishing credentials in an issue. Keep unknown, failed, skipped and stale states visible.
