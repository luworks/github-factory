# A three-minute Moonshot demo

This is a rehearsal script, not a claimed recording or competition submission. Use the final delivery report for actual provider and live-data evidence.

## 0:00 — A place to understand code

Show the landing page. “Every codebase has a world inside it. Today that world is buried in a file tree and a dozen dashboards. Moonshot gives it a place.”

Open a pre-generated OpenClaw world. Say its actual capture time and head. Identify gateway, interfaces and model-related packages only where the current source evidence supports those districts.

## 0:30 — Explore, don’t guess

Select a district. Show its path, role, observed/inferred label and source link. Follow an actual connection and open its evidence. “This is a map built from repository evidence. Where a relationship is inferred, we say so.”

Change from Moonshot to Factorio, then Civilization. The same district stays selected. “Five perspectives, one source of truth. The presentation changes; the project facts do not.”

## 1:10 — The work belongs in the world

Open Activity. Show real recent workflow runs, PRs and commits. Pick a failed or active run if the actual snapshot has one; otherwise show a successful run with its source. Do not manufacture a failure for dramatic effect. Explain the bounded recent observation window.

Refresh once. Use the returned timestamp and source state to demonstrate data retrieval. Do not claim a real project changed merely because the snapshot time advanced.

## 1:45 — An AI guide with an evidence boundary

Open the field guide. Show actual final provider `muse-spark-1.3`, generated descriptions and evidence-linked suggested missions. Show an existing source link. “Muse interprets a bounded repository survey. It cannot run repository code, create permission, or spend beyond the persisted budget.”

Show that changing styles or refreshing GitHub activity does not invoke the model again. Quote the measured token-cost estimate from the final ledger, not an invented round number.

## 2:20 — Generality

Paste an unrelated public repo such as react/react. Watch it become a different topology, not a reskinned OpenClaw diagram. Select a source-backed package and open an actual issue or workflow. A cached pre-generated example is useful for a smooth demo; say it is cached and show its collection time.

## 2:50 — Why this exists

“Moonshot helps a new contributor build a mental map, a maintainer see work in context, and the curious understand open source. Your codebase, a living world.”

## Record before sharing

- Which examples are cached and their captured heads/timestamps.
- Which paths were observed, inferred, incomplete or unavailable.
- Actual local/browser checks and untested devices.
- Persisted estimated API spend, reservations and hard cap.
- Reachable local URL; public hosting and competition submission are separate actions.
