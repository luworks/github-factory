# Integration contract

Independent project directory: code/moonshot. Types are fixed in src/contracts.ts. Each child edits only its lane. Parent owns routes, package/config, entrypoints, integration, env and commits. English is default; `Lang` toggles local English/Chinese. Five StyleIds exactly as contracts.

## Backend lane

Own `src/server/github.ts`, `analysis.ts`, `store.ts`, `service.ts`, `test/github.test.ts`, `test/analysis.test.ts`. Export `loadWorld(input: string, options?: { refresh?: boolean }): Promise<WorldSnapshot>` and `listFeatured(): Promise<FeaturedProject[]>` from service.ts. No AI calls; create evidence-grounded rules blueprint. Use env GITHUB_TOKEN, MOONSHOT_DATA_DIR. Public GitHub only, fixed api.github.com requests; no cloning, arbitrary external URL fetch, repo execution, private repo leakage or fabricated status. Snapshot captures max bounded windows and tree evidence. Cache persisted SQLite, singleflight and rate controls. Include real public curated repo defaults openclaw/openclaw, pingdotgg/t3code, react/react, pytorch/pytorch, facebookresearch/segment-anything, meta-llama/llama-models. Export parseRepo from github.ts. Explain collection partial/errors through contract.

## AI lane

Own `src/server/ai.ts`, `budget.ts`, `test/budget.test.ts`, `test/ai.test.ts`, `docs/AI.md`. Export `enrichWorld(world: WorldSnapshot, options?: { force?: boolean }): Promise<WorldSnapshot>` and `getBudgetStatus(): BudgetStatus`. Must work without key by returning explicit rules blueprint (do not call success AI). API base/model/key from server-only env. Current bootstrap uses OpenAI-compatible Responses, final Meta API https://api.meta.ai/v1 model muse-spark-1.3. Standard Meta Spark prices per 1M input=$1.25/output=$4.25 (reasoning included), Wonder input=$4/output=$20, NO contributor variant. Budget across all configured providers and calls hard-capped at $50; child makes NO paid calls. Atomic SQLite reservations before send, conservative byte-based token upper bound + bounded max_output_tokens, strict request/output/input limits, no automatic paid retries, persistent accounting, no browser trust in cost/provider. API unavailable/refused/bad JSON/incomplete must retain repo evidence and expose fallback reason. Model may relabel/explain existing node IDs and propose missions with source links, never add unsupported facts or execute generated code. Cache generated blueprint by head+prompt version+provider/model; source refresh must not regenerate. Isolate future Muse provider switch behind one interface. Parent owns env and live smoke tests.

## Frontend lane

Own `src/components/**`, `src/styles.css`, `src/client/**`, optionally `docs/DESIGN.md`. Export `LandingPage` with `{lang:Lang,onLangChange:(l:Lang)=>void}` and `ExplorerPage` with `{owner:string,repo:string,lang:Lang,onLangChange:(l:Lang)=>void}` from components/LandingPage.tsx and ExplorerPage.tsx. Parent routes embed them. May import WorldCanvas from #/world/WorldCanvas (renderer lane); that module will export props below. Data fetch via API: GET /api/gallery -> {projects:FeaturedProject[]}; POST /api/worlds {repo:string, enrich?:boolean} -> WorldSnapshot (cost only when enrich=true; default primary generate flow true); GET /api/world/$owner/$repo -> WorldSnapshot; POST same {refresh:true} -> WorldSnapshot without paid regeneration; POST /api/blueprint/$owner/$repo {force?:boolean} -> enriched WorldSnapshot; GET /api/budget -> BudgetStatus. Handle loading/error/stale/partial. Navigate to `/world/$owner/$repo` on successful import, preserve style via ?style=Id, optional lang=en|zh. Do not implement API server routes. Poll current world every 60s, foreground only, no duplicate generation. Strong product: living explorable code world, repo paste, playable curated projects, current issues/PR/CI/commits, source-linked district inspector, AI field guide/missions, provider budget visibility, five styles. Keep observed/inferred/unknown boundaries user understandable. Use lucide-react, hand-written CSS; original premium design, no copied product/game assets. Source always visible; motion is illustrative topology motion, never real visitor/load telemetry.

Canvas or SVG original isometric visual, five unmistakably distinct compositions/palettes/UI world surfaces, scales to arbitrary bounded repo nodes. Node identity stable across style switch, node activity driven only by snapshot status; decorative animation labeled by parent. Interactive hover/click/pan/zoom/reset, pointer capture/lost/cancel safe, DPR cap2, resize observer, reduced motion, empty safe. Avoid hardcoded internal repo building names. Parent owns surrounding explorer UI. HTML canvas data-testid="world-canvas"; accessible node buttons/labels or alternate inspector list. No server fetch. Pure geometry tests optional own test/world-layout.test.ts.
